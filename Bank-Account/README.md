# 🏦 JavaScript Bank Account

## 📖 Overview

This project implements a simple **Bank Account system** using JavaScript objects and object methods.

The system manages account balances and transaction history while supporting deposits, withdrawals, transfers, and balance tracking with proper validation.

## ✨ Features

### 🔹 Account Operations

Each bank account supports:

- `deposit()` — adds money to the account.
- `withdraw()` — removes money from the account when sufficient funds are available.
- `transfer()` — transfers money between accounts.
- `showBalance()` — displays the current account balance.
- `showHistory()` — displays all recorded transactions.

### 🔹 Validation

The implementation handles invalid operations such as:

- Invalid or non-positive amounts
- Insufficient funds
- Transfers to the same account

Successful operations update both the account balance and transaction history.

## 🧠 Concepts Demonstrated

- JavaScript Objects
- Object Methods
- `this` keyword
- Object state management
- Array manipulation
- Validation
- Conditional logic
- Transaction history
- Error handling

## 🎯 Goal

The main goal of this assignment is to practice **working with objects and object methods in JavaScript** by building a simple system that simulates common bank account operations.

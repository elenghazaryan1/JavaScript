# ⚡ Fetch API Playground

> A collection of JavaScript exercises for mastering the **Fetch API**, Promises, and array methods through real API data.

---

## 🧠 What I'm Practicing

This project focuses on taking data from APIs and actually **working with it** using modern JavaScript.

| Topic          | What I practice                     |
| -------------- | ----------------------------------- |
| 🌐 Fetch API   | Sending requests and receiving data |
| 📦 JSON        | Parsing API responses               |
| 🔎 `find()`    | Finding a specific item             |
| 🧹 `filter()`  | Selecting items by a condition      |
| 🔄 `map()`     | Transforming API data               |
| 📊 `reduce()`  | Finding/calculating values          |
| 🧩 Objects     | Working with nested API data        |
| ⚠️ Error cases | Handling missing results            |

---

## 📂 Exercises

### 👤 Users

**API:** `randomuser.me`

Practice working with user data:

- Filter users by age
- Find people younger than a specific age
- Extract users' names
- Work with nested properties like `dob.age` and `name.first`

---

### 🛍️ Products

Practice working with product data:

- Find the **most expensive product**
- Compare product prices using `reduce()` or sorting

---

### 📝 Posts

**API:** `jsonplaceholder.typicode.com`

Practice working with posts:

- Count the number of posts belonging to a user
- Find a post by its `id`
- Handle cases where a post doesn't exist

---

# 📘 JavaScript Method Implementations

## 📖 Overview

This project contains custom implementations of common JavaScript **Array** and **Function** prototype methods.

The goal is to recreate the core behavior of native JavaScript methods while working with prototypes, callbacks, execution context, arguments, return values, and edge cases.

## ✨ Features

### 🔹 Array Prototype Methods

Custom implementations of:

**Mutating Methods**

- `myPush()`
- `myPop()`
- `myShift()`
- `myUnshift()`
- `mySplice()`

**Iterating Methods**

- `myForEach()`
- `myMap()`
- `myFilter()`
- `myReduce()`
- `mySome()`
- `myEvery()`

**Searching & Copying Methods**

- `myFind()`
- `myFindIndex()`
- `myIncludes()`
- `mySlice()`

Implementations account for callback execution, `thisArg` context, empty arrays, initial values, and edge cases such as `NaN`.

### 🔹 Function Prototype Methods

Custom implementations of:

- `myCall()`
- `myApply()`
- `myBind()`

These methods demonstrate how JavaScript controls the execution context of functions through `this`, handles arguments, preserves return values, and supports partial application through `bind`.

## 🧠 Concepts Demonstrated

- Array prototypes
- Function prototypes
- Callback functions
- `this` context
- `call()`, `apply()`, and `bind()`
- `thisArg`
- Higher-order functions
- Closures
- Argument handling
- Mutating vs non-mutating methods
- Array iteration
- Edge case handling
- `NaN` comparison
- Currying / partial application

## 🎯 Goal

The main goal of this project is to understand **how JavaScript's built-in Array and Function methods work internally** by recreating their behavior using prototypes and fundamental JavaScript concepts.

# 📘 JavaScript Destructuring

## 📖 Overview

This project contains a collection of JavaScript exercises focused on **destructuring assignment** and its practical use with arrays and objects.

The tasks explore how destructuring can be used to extract, rename, skip, and organize values in a clean and efficient way.

## ✨ Features

### 🔹 Array Destructuring

Working with array values using:

- Basic destructuring
- Skipping elements
- Default values
- Rest syntax
- Nested arrays

### 🔹 Object Destructuring

Working with object properties using:

- Property extraction
- Renaming variables
- Default values
- Rest syntax
- Nested objects

### 🔹 Function Parameters

Using destructuring directly in function parameters to work with structured data more efficiently.

### 🔹 Practical Exercises

The project includes different tasks that demonstrate how destructuring can simplify common JavaScript operations and make code more readable.

## 🧠 Concepts Demonstrated

- Array destructuring
- Object destructuring
- Nested destructuring
- Default values
- Rest syntax
- Variable renaming
- Function parameter destructuring
- Spread & rest operators
- Modern JavaScript syntax

## 🎯 Goal

The main goal of this project is to understand **how destructuring works in JavaScript** and how it can be used to write cleaner, shorter, and more readable code when working with arrays and objects.

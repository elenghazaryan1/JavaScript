# 📘 JavaScript Methods Implementation

## 📖 Overview

This project contains a collection of custom JavaScript method implementations created to better understand how common built-in methods work internally.

The implementations focus on **arrays, strings, objects, type checking, comparisons, and utility functions**, using core JavaScript concepts without relying directly on the built-in methods being recreated.

## ✨ Features

### 🔹 Boolean Value

Converts and evaluates values according to JavaScript's boolean behavior.

### 🔹 Character & Number Utilities

Functions for working with characters, numbers, and their relationships.

### 🔹 Compare Values

Custom comparison utilities for checking and evaluating different values.

### 🔹 Find Index

Searches for elements and returns their corresponding index.

### 🔹 Is Plain Object

Determines whether a given value is a plain JavaScript object.

### 🔹 Odd or Even

Checks whether a number is odd or even.

### 🔹 Array Utilities

Custom implementations of common array operations such as searching, transforming, and processing elements.

### 🔹 String Utilities

Functions for manipulating and working with string values.

### 🔹 Type Checking

Utilities for identifying and validating JavaScript data types.

## 🧠 Concepts Demonstrated

- JavaScript built-in methods
- Arrays & Strings
- Objects
- Type coercion
- Strict equality
- `typeof`
- Prototype chain
- Iteration & loops
- Callback functions
- Edge case handling
- Custom method implementation
- Error handling

## 🎯 Goal

The main goal of this project is to understand **how common JavaScript methods and utilities work internally** by recreating their behavior using fundamental JavaScript concepts.

# 📘 JavaScript Functional Programming Utilities

## 📖 Overview

This project contains custom implementations of several JavaScript function utilities focused on **functional programming, closures, higher-order functions, and function composition**.

The implementations demonstrate how functions can be transformed, combined, optimized, and controlled through reusable functional patterns.

## ✨ Features

### 🔹 Function Utilities

Custom implementations of:

- `curry()` — transforms a function into a sequence of functions accepting arguments incrementally.
- `memoize()` — caches function results to avoid unnecessary repeated calculations.
- `pipe()` — combines functions and passes the result of one function into the next.
- `trace()` — wraps a function to track its calls, arguments, and results.

## 🧠 Concepts Demonstrated

- Higher-order functions
- Closures
- Currying
- Memoization
- Function composition
- Data flow
- Callback functions
- Rest & spread syntax
- Function execution
- Caching
- Reusable abstractions

## 🎯 Goal

The main goal of this project is to understand **functional programming concepts in JavaScript** by implementing common function utilities from scratch and exploring how closures and higher-order functions can be used to control and compose behavior.

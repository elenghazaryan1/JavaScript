# 🔄 Symbol Iterator

A collection of JavaScript exercises focused on **well-known Symbols** and custom object behavior.

## 📚 Exercises

- `iterator1.js` — `Symbol.iterator`
- `iterator2.js` — `Symbol.hasInstance`
- `iterator3.js` — `Symbol.toPrimitive`
- `iterator4.js` — additional Symbol practice

## 🧠 Concepts

- Custom iterators
- `for...of`
- `next()` and iterator protocol
- Custom `instanceof` behavior
- Primitive conversion
- `string`, `number`, and `default` hints

✨ Small exercises, deeper understanding of JavaScript internals .
